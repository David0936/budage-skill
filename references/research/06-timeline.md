# 06 人生时间线

> 素材来源：百度百科 + 多知网 / 腾讯新闻（2021.12）+ i黑马 / 新浪财经（2021.11）+ 36氪 / 芥末堆 / 铅笔道 + 《虎言乱语》播客 Vol.21（2022.08）+ 微信读书《短视频流量密码》出版信息 + 《不答哥心法全集》PDF
> 调研日期：2026-05-09

不答哥（覃流星 / 阿星 / Alex）的公开履历可以分成两个截然不同的阶段：**2007-2022 年的"公开报道密集期"**——主流财经媒体、教培媒体、播客都在报道；以及**2023 年至今的"私域阶段"**——主要在视频号 / 抖音 / 火种计划社群内活动，外部主流媒体几乎不再点名报道。两阶段的语料密度差异，是阅读这条时间线时需要先预备好的背景。

## 八、阅读建议

如果带着研究目的看这条时间线，建议把注意力放在三个"拐点"上：

1. **2014 离开新东方** —— 第一次主动放下身份，建立"放下"心理肌肉
2. **2021 廖恒悦 U 盾事件** —— 一夜之间把咨询课加价 10 倍，确立"网红校长"高光，也埋下"镰刀工厂"标签
3. **2022 教培归零** —— 第二次主动放下身份，从"网红校长"重置为"不答哥"，从 ego 驱动转向使命驱动

把这三个拐点连起来，能看出他这个 IP 最深的内核不是「日更 100 条」也不是「29.8 万咨询课」，是**反复"放下身份"的能力**——这是他和大多数知识付费 IP 最不一样的地方。
