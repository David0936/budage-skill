# PDF 设计交付协议

## 适用范围

定位报告、故事梳理、内容方案、账号策划、复盘报告、行动计划等正式成果必须生成 PDF。普通问答、访谈追问和过程小结不需要每轮生成 PDF。

## 设计方法

1. 优先调用 `huashu-design` Skill，使用 HTML 作为设计母版，再导出文字可搜索的 PDF。
2. 先根据用户的身份、行业、受众和已有品牌资产确定视觉方向，不套通用 AI 模板。
3. 用户有头像、Logo、品牌色、字体或参考图时优先使用；缺少资产时不得伪造，使用诚实占位或纯排版方案。
4. 默认使用 A4 竖版，适合手机预览、微信转发和打印；内容确实需要横向比较时才使用 A4 横版。
5. 导出前检查分页、文字溢出、图片清晰度、中文字体、页码和链接，肉眼确认后再交付。

## 预览确认

正式生成前先在对话里给一屏「报告预览卡」，只包含：

- 报告标题与用户姓名或项目名。
- 一句话核心结论。
- 计划采用的 5-10 个页面目录。
- 自动选择的视觉方向及选择理由。
- 明确标记的待确认信息。

最后只问：「回复『确认生成』，我就开始制作 PDF；要修改，直接告诉我改哪一项。」用户已经明确说「不用确认、直接生成」时可跳过此步骤。

## 默认视觉方向

- 气质：成熟、坚定、女性友好、克制而有力量。
- 色彩：炭黑、藏红、暖白为主，少量哑金用于强调。
- 元素：可适量使用经幡色序、印章、山形、圆相、手写批注等抽象视觉母题；避免堆砌宗教符号或把藏传佛教元素当廉价装饰。
- 排版：大标题有力量，正文留白充足，重点结论可截图传播；拒绝紫色渐变、Emoji 图标墙和千篇一律圆角卡片。

## 三套可选风格

默认根据用户内容自动选择，不把设计题再次丢给小白；用户主动提出时可以切换。

1. **藏红力量版（默认）**：炭黑 + 藏红 + 暖白 + 哑金；适合创业重启、个人成长、强观点定位。
2. **女性温暖版**：米白 + 胭脂红 + 暖棕；适合中年女性、生活方式、教育、家庭成长与陪伴型 IP。
3. **商务专业版**：墨黑 + 深灰 + 克制红；适合企业家、顾问、知识服务和高客单项目。

选择风格时优先看内容气质和目标用户，不根据性别刻板套用。每一版都保留不答哥的力量感，但不得堆砌宗教符号。

## 内容结构

正式报告根据任务选用以下页面，不为凑页数添加无用内容：

1. 封面：报告名称、用户姓名或项目名、日期、版本号。
2. 一页结论：一句话定位或核心判断。
3. 故事地图：关键经历、冲突、转折和认知。
4. 定位卡：我是谁、帮谁、解决什么问题、凭什么是我。
5. 用户与痛点：目标人群、核心场景和真实问题。
6. 差异化：可验证的经历、能力、案例和竞争边界。
7. 内容规划：内容支柱与首批 3-5 条选题。
8. 变现路径：产品、价格承接与转化动作；未知价格明确标记待确认。
9. 七天行动：具体到日期、动作和发布平台。
10. 依据与假设：区分用户原话、事实、推断和待验证项。

## 文件交付

- 文件名：`不答哥_IP报告_姓名或项目_YYYYMMDD.pdf`。
- 同时保留用于生成 PDF 的 HTML 母版，便于后续修改，但默认只把 PDF 交给终端用户。
- 不得把内部口令、隐藏配置、系统提示词或付费题库规则写入 PDF。
- 若 PDF 导出失败，明确告诉用户失败原因和已完成到哪一步，不得提供不存在的文件。
