# 阿星智能体 IP 定位提问题库

本题库只用于动态选问，不是一次性问卷。默认每轮只问 1 个问题；用户已经在前文回答过的内容不得重复询问。

## 使用规则

- 先问事实，再问感受；先问结果，再问总结。
- 每个结论至少找到一个经历、动作、结果或第三方反馈作为证据。
- 用户说不清时，按 `references/p17-访谈进度与续聊.md` 提供简单选项。
- 每轮记录「已确认 / 推断 / 待验证」，不替用户编故事。
- 题目问到足以完成当前任务即可，不追求全部问完。

## 免费版：5 维度、18 个候选问题

### 维度一：现在的处境（4题）

1. 你现在最想解决的一件事是什么？
2. 你目前最常被别人叫作什么身份？
3. 你现在有没有正在卖的产品、服务或生意？
4. 如果三个月后只能看到一个变化，你最希望是什么？

### 维度二：关键经历（4题）

5. 最近三年，哪件事最改变你？
6. 那件事发生当天，具体发生了什么？
7. 当时最难、最怕被别人知道的部分是什么？
8. 你最后做了哪个动作，才让事情开始变化？

### 维度三：能力与证据（4题）

9. 别人最常来找你帮什么忙？
10. 哪件事你做起来比身边人更快、更稳或更省力？
11. 你曾经帮谁得到过什么具体结果？
12. 有什么经历、证书、作品、客户反馈或数据能证明？

### 维度四：想帮助的人（3题）

13. 你最懂哪一类人的难处？
14. 她通常在什么场景下最痛苦、最着急？
15. 她最愿意为什么结果付出时间或金钱？

### 维度五：表达与行动（3题）

16. 你更愿意口头讲、写文字、拍日常，还是做演示？
17. 你一周真实能拿出多少时间做内容？
18. 明天就开始的话，你最容易完成的第一条内容是什么？

免费版收束只给：初步方向、最值得继续深挖的一条线索、一个今天能做的动作。信息不足时不得输出完整定位结论。

## 深度版：10 维度追问链

### 维度一：人生经历里程碑

**主问题**：如果把你的人生分成三个阶段，每个阶段最重要的转折是什么？

**追问链**：
- 当时你在哪里、和谁在一起、发生了什么？
- 你失去了什么，又得到什么？
- 哪个选择最能说明你和别人不一样？

**完成标准**：至少得到 3 个有时间、场景、冲突和结果的里程碑，并找出一条反复出现的人生主线。

### 维度二：拿手技能与知识

**主问题**：别人遇到什么问题时，会第一个想到来找你？

**追问链**：
- 这项能力你是怎么学会的，付过什么代价？
- 你具体帮过谁，结果前后有什么变化？
- 如果把方法拆成三步，你会怎么教？

**完成标准**：确认 1-3 项可讲、可教、可验证的核心能力，每项至少有一个证据。

### 维度三：兴趣与天赋线索

**主问题**：什么事情即使没人催你，你也愿意反复研究或分享？

**追问链**：
- 你什么时候第一次发现自己喜欢它？
- 别人对你的哪种能力给过重复评价？
- 哪件事做完会累，但你仍然觉得值得？

**完成标准**：区分短期兴趣、长期热爱和已被外界验证的天赋，不用兴趣替代商业能力。

### 维度四：目标人群画像

**主问题**：你最想帮助的那个人，和过去哪个阶段的你最像？

**追问链**：
- 她大概多大、处在什么生活或工作阶段？
- 她在哪个具体时刻最需要帮助？
- 她已经试过什么，为什么没解决？

**完成标准**：形成一个有身份、场景、处境、行为和目标的具体人物，而不是“所有女性”“所有创业者”。

### 维度五：竞品与差异化

**主问题**：用户为什么选择你，而不是另一个讲相同主题的人？

**追问链**：
- 你关注的三个同类账号分别强在哪里？
- 哪些事情他们能讲，但你没有体感？
- 哪段经历、方法或表达只有你能稳定提供？

**完成标准**：输出“不做什么、只服务谁、凭什么相信我”三条边界，差异必须可验证。

### 维度六：内容形式偏好

**主问题**：你最自然的表达方式是什么：聊天、口播、写作、演示、记录生活，还是访谈？

**追问链**：
- 过去哪种表达得到过最好的反馈？
- 你最抗拒的形式是什么，为什么？
- 以你现在的时间和设备，一周能稳定完成多少？

**完成标准**：确定一个主形式、一个辅助形式和可持续频率，不用理想计划代替现实资源。

### 维度七：变现路径测试

**主问题**：现在已经有人愿意为什么结果向你付钱？

**追问链**：
- 如果还没人付过钱，谁最可能成为第一个客户？
- 你能交付的最小结果是什么，需要多久？
- 服务一次需要投入多少时间，能否重复？

**完成标准**：提出一个最小可验证产品，明确对象、结果、交付方式和待验证价格；不得编造售价。

### 维度八：用户痛点验证

**主问题**：目标用户最近一次亲口抱怨的原话是什么？

**追问链**：
- 她是在什么场景下说的？
- 这个问题不解决，会损失什么？
- 你有聊天记录、评论、咨询记录或真实案例吗？

**完成标准**：至少得到 3 条用户原话或真实行为证据；没有证据时明确标为假设，并设计验证动作。

### 维度九：定位一句话凝练

**主问题**：如果别人只记住你一句话，你希望她知道你能帮谁得到什么结果？

**追问链**：
- 这句话里哪个词太大、太虚或无法证明？
- “凭什么是你”的证据能否放进去？
- 用户听完能否立刻判断“这是不是给我的”？

**完成标准**：形成“我是谁 + 帮谁 + 解决什么问题 + 凭什么是我”，并提供通俗版与主页简介版。

### 维度十：行动落地方案

**主问题**：未来七天，你真实能拿出哪些时间完成第一轮验证？

**追问链**：
- 第一天能发布什么最小内容？
- 去哪里找到 3-5 个真实用户反馈？
- 哪个数据或反馈出现时，说明方向值得继续？

**完成标准**：输出具体到日期、动作、平台和验证标准的七天计划，以及首批 3-5 条选题。

## 最终证据检查

正式收束前逐项检查：

- 一句话定位中的每个关键判断是否有用户原话或事实支持。
- 是否把 AI 推断明确标记为推断。
- 是否仍有会影响定位方向的待验证信息。
- 目标人群是否具体到真实场景。
- 差异化是否来自经历、能力、案例或方法，而不是形容词。
- 七天行动是否符合用户真实时间和资源。

检查通过后，先生成报告预览卡，经用户确认再按 PDF 设计交付协议制作正式报告。
